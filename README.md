# Soft Computing and Optimization Algorithms (SCOA)

This repository contains implementations of various soft computing and optimization techniques.

## Assignments

### Assignment 1
Implement mathematical operations on fuzzy sets. Also create fuzzy relations by Cartesian product of any two fuzzy sets and perform max-min composition on any two fuzzy relations.

### Assignment 2
Write a program to apply fuzzy logic for controlling a simulated robotic arm using fuzzy logic.

### Assignment 3
Write a program to optimize the parameters of a machine learning model using Genetic Algorithm.

### Assignment 4
Write a program to predict stock market trends using an artificial neural network.

### Assignment 5
Write a program to optimize the layout of a warehouse or Data Clustering problem using particle swarm optimization algorithm.

## Usage

Each assignment is implemented in its respective directory with source code and documentation.

## Requirements

Requirements and dependencies will be specified in individual assignment directories.
